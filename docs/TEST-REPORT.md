## 3. 缺陷清单

### P0-1 淹没分析「水位上涨」动画完全不生效

- **复现**：水库淹没分析 → 点「▶ 水位上涨」→ 按钮变为「⏸ 暂停」，但水位读数 4 秒内始终停在 210m，淹没面积不变。
- **期望**：水位按 2.4 m/s 上涨，水面/面积实时跟随。
- **根因**：`tick()` 里 `let lv = level.value + riseRate * dt` 之后立刻 `Math.round(lv * 10) / 10`。每帧增量约 `2.4 × 0.016 = 0.04m`，四舍五入回原值，累加基准被"钉死"，永远不动。
- **修复**：新增未取整的浮点累加器 `levelAcc`，只在写入 `level` 时取整。
- **验证**：水位 210 → 214 → 217 → 221，淹没面积 16.32 → 17.60 km²。

### P0-2 时序影像「播放」不推进

- **复现**：点「▶ 播放」后年份恒定在 2001，进度点不动。
- **根因**：同 P0-1，`frameIdx.value = Math.round(next)`；每帧只加 `dt × speed ≈ 0.02` 期，`round` 后回到同一期。
- **修复**：改用 `frameAcc` 累计 + `Math.floor`。
- **验证**：播放后年份 2003 → 2005 → 2009 → 2011 正常推进。

### P0-3 时序影像「播放 → 对比 2001 → 前一期」整页渲染中断

- **现象**：控制台抛 `DeveloperError: Expected width to be greater than 0, actual value was 0`，Cesium 弹出「Rendering has stopped」，画布黑屏。**必现**。
- **根因**：`makeTextureUploader` 换帧时立即 `close()` 旧 `ImageBitmap`，而 Cesium 是在**下一帧** `Material.update` 里才把该位图上传成纹理，此时读到已释放位图（`width = 0`）。播放动画 + 切换卷帘对比时换帧最频繁，因此必现。
- **影响面**：所有使用该上传器的 6 个分析页（terrain-dem / cut-fill / flood / viewshed / time-series / mask-clip）。
- **修复**：旧位图延迟 1.5s 回收（被 seq 判废、从未挂到 uniform 的位图仍立即释放）。
- **验证**：同一序列连点不再报错；`--disable-gpu` 软件渲染下同样正常。

### P0-4 掩膜裁剪：三种模式全部失效且语义反了

三个独立缺陷叠在同一页：

1. **切模式画面不变**：`refresh(false)` 只重传贴图，不同步 `uMode` / `uFeather` 两个不参与 SDF 烘焙的 uniform → 「挖除内部」「仅边界带」永远沿用初始的 keep。
2. **「保留内部」把内部压暗**：`sdShape()` 是标准 SDF 约定（**内部为负**），shader 里按「正 = 内部」使用，导致 `inside` 恰好是反的。
3. **裁剪平面方向反了**：Cesium 在 `dot(n,p) + d < 0` 处裁掉，法线朝外裁的是内部；而「保留内部」应当保留内部。

- **修复**：SDF 编码改为 `0.5 - 0.5 * clamp(dist / RANGE)`；非重建路径显式同步 `uMode` / `uFeather`；`keepInside` 时反转法线。
- **验证**：三种模式视觉各不相同（内部保留 / 内部压暗 / 仅青色边界带）；开裁剪平面后地形只在掩膜内保留。

### P0-5 蜂窝聚合完全失效（一点一格）

- **现象**：4040 个轨迹点聚合出 4040 个蜂窝，`单格峰值` 恒为 1，热力着色全无意义。
- **根因**：`pixelToHex()` 立方取整后返回的是 `[cx, cz]` —— 即**未取整的浮点轴坐标**，修正值只写进了局部变量没写回返回值。于是每个点都落进独一无二的 key。
- **修复**：三向取整 → 偏差最大维反推修正 → 返回修正后的整数 `[rx, rz]`。
- **验证**：814 格 / 峰值 118；尺寸拉到 900m 后 307 格 / 峰值 289。

### P1-6 地形剖面「线路长」错误（874km）

- **现象**：示例线显示 `874.59 km`，而该示例区域仅 9km 见方；手绘短线也会给出几百公里。
- **根因**：采样点累加的是「本点 − 本段起点」而不是「本点 − 上一点」。同一条线段内 320 个采样点会把 `f × segLen` 反复累加，误差与采样数成正比。
- **修复**：记录上一个采样点坐标，按「点间距离」累加。
- **验证**：示例线 10.94 km、手绘线 16.63 km，爬升/坡度随之重算，数值合理。

### P2-7 掩膜裁剪默认取景把掩膜甩出画面

- **现象**：进入页面时掩膜多边形落在画面右下角，大半在视口外，需要手动拖回来才看得到效果。
- **根因**：机位 `LAT - 0.055`（约 6km）配 34km 高度、-58° 俯角，视线实际落在掩膜中心以北约 15km。
- **修复**：按 `命中距离 = 高度 / tan(俯角)` 反算机位，`dLat` 改为 0.2138。
- **验证**：掩膜居中且完整可见。

### P2-8 三维地形页启用 `highDynamicRange`

- **现象**：用户反馈该页出现 `Fragment shader failed to compile` 且整页黑屏（本地无法复现，Chrome 硬件/软件渲染、Edge 均正常）。
- **定位**：该页是**唯一**设置 `scene.highDynamicRange = true` 的页面，而 HDR 会启用 `czm_tonemapping` 着色器分支，在部分驱动/软件回退下编译失败。
- **修复**：移除 HDR（该页视觉几乎无差异）。
- **备注**：属"未完全复现但已消除风险项"，列入观察清单。

## 4. 复核后判定为「非缺陷」的项

| 现象 | 复核结论 |
| --- | --- |
| 改「太阳方位」画面不变 | 测试序列先把「晕渲强度」调到 0，晕渲权重为 0 时改太阳角本就不会有变化；恢复 75% 后画面差 5.61，功能正常 |
| 「设计面 / 方格网 / 零线」开关画面差 < 1.5 | 半透明叠层 + 细线，全图平均差天然很小；逐项目视确认均生效，判定阈值问题 |
| 时序影像「前后一期」画面差 0.4 | 相邻两期只差建成区几十 km²，年份读数确实变化（2001 → 2003），属内容差异小 |
| OL「示例线」点击后统计不变 | 页面挂载时已自动画过示例线，重复点击结果相同 |
| 掩膜「边数」滑块在圆形下无效 | 圆形不使用边数，属设计如此 |
| 3 个暗色页面被像素体检判为 DARK | 描边/粒子/点精灵本就是黑底场景 |

## 6. 遗留风险

1. `highDynamicRange` 在其他两个示例（`heatmap-overlay`、`sun-shadow`）仍在用，本轮未观察到问题，但若同类报错复现可优先怀疑此处。
2. 纹理上传的延迟回收引入 2~3 帧的位图滞留，内存占用可忽略（720²×4B ≈ 2MB/张，最多同时 2 张）。
3. 外部依赖（Esri 瓦片、glTF CDN）在弱网下会有 5~10s 空白期，属网络问题而非应用缺陷。
